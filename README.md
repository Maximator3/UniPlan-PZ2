# UniPlan — ПЗ №2 (варіант B, AI-first)

React/Vite-версія інтерактивного прототипу UniPlan з винесеним повторно використовуваним UI-kit і Storybook-історіями. Код перенесено з наданого автономного HTML-прототипу; екранні сценарії та `localStorage` збережено.

## Вимоги
- Node.js 20+ (рекомендовано 22 LTS)
- npm 10+
- Інтернет для першого завантаження пакетів (`npm install`)

## Запуск застосунку
```bash
npm install
npm run dev
```
Відкрийте адресу, яку покаже Vite (за звичайного запуску — `http://127.0.0.1:5173`).

## Запуск UI-kit у Storybook
```bash
npm run storybook
```
Відкрийте `http://localhost:6006`. У лівому меню відкрийте **UI-kit** та **Design system / Tokens**. Для кнопок є історії Default, Hover, Active, Disabled; для інпутів — Default, Required, WithHint, Invalid, Disabled, Focus. Інші компоненти також мають окремі історії.

## Екрани застосунку
- Огляд / Дашборд
- Завдання
- Календар
- Розклад
- Предмети
- Налаштування

## Перевірка user flow
1. У розділі «Предмети» додайте новий предмет.
2. У «Завданнях» створіть завдання й задайте термін.
3. Знайдіть дедлайн у «Календарі» та відкрийте картку.
4. Створіть підзадачу, позначте її виконаною й перевірте прогрес.
5. Поверніться на «Огляд» — показники мають оновитися.
6. Оновіть сторінку — збережені дані повинні залишитися в цьому браузері.

## Побудова
```bash
npm run build
npm run build-storybook
```

## Структура
- `src/components/index.js` — власний UI-kit (11 компонентів)
- `src/stories/` — окрема група Storybook-історій кожного компонента плюс токени
- `src/App.js` — екрани, стани та бізнес-логіка прототипу
- `src/styles.css` — стилі та дизайн-токени
- `docs/moodboard.html` — посилання на 7 візуальних референсів

## Важливо
Кодову структуру підготовлено для запуску в Vite/Storybook; перед здачею запустіть проєкт локально, переконайтеся у відсутності помилок у консолі та перевірте всі переходи. Сам факт наявності файлів не є доказом успішного запуску чи проходження тестів. Для звіту потрібно додати GitHub URL після власного завантаження репозиторію.
